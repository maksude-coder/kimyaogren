## Milestone Status Definitions

| Status | Meaning |
|--------|---------|
| ⏳ Pending | Not started |
| 🟢 In Progress | Actively being worked on |
| 🟡 At Risk | Blockers or behind schedule |
| ✅ Done | All DoD criteria met, accepted by PM |
| ❌ Deferred | Moved to later milestone |
| 🚫 Cancelled | No longer needed |

---

## Milestone Review Process

1. **Pre-Milestone** (1 week before): PM reviews readiness with team
2. **Milestone Demo**: Working software demonstrated to PM
3. **Acceptance**: PM verifies Definition of Done
4. **Retrospective**: 30-min review of what worked/didn't
5. **Documentation**: Update changelog, close milestone
