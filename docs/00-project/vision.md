# Project Vision

## Purpose
Defines the long-term vision and north star for KimyaÖğren. All product and technical decisions should align with this vision.

---

## Vision Statement

> **Build the most effective, curriculum-aligned chemistry learning platform for Turkish high school students preparing for YKS (Yükseköğretim Kurumları Sınavı).**

---

## Target Audience

| Primary | Secondary |
|---------|-----------|
| 9th-12th grade Turkish students | Chemistry teachers |
| YKS exam candidates | Private tutors |
| | Parents monitoring progress |

---

## Core Value Proposition

| Problem | Solution |
|---------|----------|
| Textbooks are static and passive | Interactive theory with simulations |
| Practice questions lack explanations | Every question has step-by-step solution |
| No personalization | Spaced repetition + mastery tracking |
| Misaligned with MEB curriculum | 100% MEB/YKS aligned content |
| No progress visibility | Real-time dashboards for students/teachers |

---

## Success Metrics (North Star)

| Metric | Target | Timeline |
|--------|--------|----------|
| Monthly Active Students | 50,000+ | Year 2 |
| Question Completion Rate | > 70% | Year 1 |
| 30-Day Retention | > 40% | Year 1 |
| YKS Score Improvement | Measurable | Year 2 |
| MEB Curriculum Coverage | 100% | Year 1 |

---

## Strategic Pillars

### 1. Curriculum Alignment First
- Every topic maps to MEB learning objectives
- YKS question formats replicated exactly
- Teacher review workflow for content accuracy

### 2. Learning Science Applied
- Spaced repetition algorithm
- Mastery-based progression
- Immediate feedback with explanations
- Cognitive load optimization

### 3. Teacher Empowerment
- Content creation tools (not just consumption)
- Class analytics and intervention alerts
- Assignment builder with auto-grading

### 4. Mobile-First Accessibility
- PWA for offline study
- Responsive design (no native app needed initially)
- Low-bandwidth optimization

### 5. Data-Driven Iteration
- A/B testing framework
- Learning analytics pipeline
- Continuous content improvement loop

---

## Non-Goals (Explicitly Out of Scope)

| Non-Goal | Reason |
|----------|--------|
| AI-generated content | Quality control risk |
| Social features (chat, forums) | Moderation burden, distraction |
| Video streaming platform | Use YouTube/Vimeo embeds |
| Multi-language support | Turkish focus first |
| Gamification (badges, leaderboards) | Extrinsic motivation undermines learning |
| Parent portal (beyond progress view) | Student autonomy priority |

---

## Long-Term Vision (5 Years)

1. **Year 1**: Chemistry 9-12 complete, YKS simulation, core analytics
2. **Year 2**: Physics, Biology domains; adaptive learning engine
3. **Year 3**: Middle school (5-8) expansion; AI-powered tutoring
4. **Year 4**: University prep expansion (ALES, YÖS); teacher marketplace
5. **Year 5**: International curriculum variants; platform licensing
